This is the list of every architecture decision record. Open it to find the decision behind a rule before you change the rule, and to take the next free number when you record a new decision.

## How to read the status

| Status     | Meaning                                                                                                                          |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Accepted   | Decided by the owner, the Technical Reference baseline or the merged repository. Follow it.                                      |
| Proposed   | An engineering recommendation or coordinator ruling awaiting the owner's confirmation. Follow it until the owner says otherwise. |
| Deferred   | Decided, but for a later release.                                                                                                |
| Superseded | Replaced by the ADR named in its status line.                                                                                    |

## Adding an ADR

1. Copy the [template](1MM-ADR-0000-TEMPLATE.md) to `1MM-ADR-<next number>-<UPPER-KEBAB-TITLE>.md`. The next free number is **0082**.
2. Record the decision first in the Technical Reference extensions log when it extends the Technical Reference ([1MM-LOG-03](../1MM-LOG-03-TECHNICAL-REFERENCE-EXTENSIONS.md)).
3. Add its row to this index in the same pull request. Never renumber or delete an ADR: supersede it.
